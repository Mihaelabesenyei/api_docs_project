# Order Management API Documentation

## Overview

This repository contains the documentation for the Order Management API.

The API allows applications to:

* Retrieve orders
* Create orders
* View order details

## Documentation Files

| File          | Description           |
| ------------- | --------------------- |
| overview.xml  | General API overview  |
| endpoints.xml | Endpoint descriptions |
| errors.xml    | Error code reference  |
